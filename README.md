The Microarcsecond Astrometric Retrieval Algorithm (MARA) is a planet detection and characterization pipeline designed for binary relative astrometry. The code uses periodogram and MAP analysis for rapid planet detection and MCMC for orbital characterization. It implements the higher-order effects required for astrometric predictions of ~1 microarcsecond.

MARA was built by modifying the orbitize! orbit fitting module, and the planet detection code is based on the RVSearch module. MARA is still under development, but the tagged version works correctly for fits to planet-only separation change and full binary separation as seen from the Solar System barycenter.
